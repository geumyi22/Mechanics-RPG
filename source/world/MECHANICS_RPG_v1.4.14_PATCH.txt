메크닉스 RPG v1.4.14 PATCH

[상점 주민]
- OP 주민 상호작용 메뉴에 주민 설정 추가
- 주민 설정 > 퀘스트 주민 설정 / 상점 주민 설정 분리
- 상점 주민 설정에서 손에 든 아이템을 상품으로 등록
- 상품별 표시 이름(선택), 1회 구매 수량, 골드 가격, 활성/비활성 설정
- 상품 수정/교체/삭제, 상점 이름/활성 상태 관리, 플레이어 화면 미리보기
- 플레이어는 기존 rpg_gold 골드를 사용해 상품 구매
- 상품 등록 시 아이템 ID 직접 입력 불필요
- 이름표, Lore, 내구도, 인챈트, 아이템 동적 속성을 가능한 범위에서 복원

- 감염된 어두운 스컬크 영역에 청백색 발광 점박이 추가

- 불/영혼불/용암 직접 접촉은 보호 대상에서 제외 유지
