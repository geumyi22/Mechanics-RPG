Geumyi RPG v0.7.0 QUEST EDITOR

[핵심]
- OP가 주민과 상호작용하면 퀘스트 관리 버튼 표시
- 일반 플레이어는 퀘스트 수락/진행/완료 UI만 표시
- 주민 1명당 최대 8개 퀘스트
- 플레이어 동시 진행 최대 10개
- 목표: 몬스터 처치 / 아이템 수집(선택 제출) / 특정 위치 도달
- 보상: 골드 / 크리스탈 / 경험치 포인트 / 아이템
- 퀘스트 활성/비활성, 반복 여부, NPC 이름, 대사, 목표, 보상 인게임 수정
- 삭제된 퀘스트도 이미 수락한 플레이어는 기존 진행본 완료 가능
- /function rpg/quest/log : 진행 중 퀘스트 일지
- /function rpg/quest/help : 간단 도움말

[OP 사용법]
1. 주민을 상호작용한다.
2. '퀘스트 관리' 선택.
3. NPC 이름 설정 또는 새 퀘스트 만들기.
4. 기본 설정 -> 목표 설정 -> 보상 설정 -> 저장.

[주의]
- 퀘스트가 설정된 주민은 일반 거래 대신 퀘스트 UI가 열린다.
- 아직 퀘스트가 없는 주민도 OP가 상호작용하면 설정 UI가 열린다.
