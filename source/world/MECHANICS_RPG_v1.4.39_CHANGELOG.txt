Mechanics RPG v1.4.39 - SUBSPACE ALL-VISIBLE-ITEM REVIEW FIX

[재검토에서 발견한 문제]
- v1.4.38의 넣기 9x4 그리드는 isPlain=false인 아이템을 빈 슬롯으로 렌더링했음.
- 따라서 내구도/특수 데이터가 있는 아이템은 '보관 불가'일 뿐인데도 이미지 누락처럼 보일 수 있었음.
- 폼을 열어 둔 사이 같은 인벤토리 슬롯의 아이템이 바뀌면 표시 당시 항목과 선택 시 항목이 달라질 여지가 있었음.

[수정]
- 인벤토리에 실제 아이템이 있으면 보관 가능 여부와 무관하게 실제 native/custom 아이콘과 이름을 표시.
- 보관 불가 아이템은 툴팁에 (보관 불가) 표시 후 클릭 시 안전 안내만 수행.
- 넣기 메뉴 표시 당시 36칸 스냅샷을 보관하고 선택 시 현재 인벤토리와 재비교.
- 빈 칸/보관 불가 항목 재선택은 재귀 호출 대신 동일 메뉴 루프로 재표시하여 불필요한 Promise 체인 제거.

[유지]
- v1.4.37에서 실기기 확인된 native raw renderer 방식 유지.
- Mojang Bedrock samples 1.26.50.4 기준 1,623개 바닐라 raw renderer ID 매핑 유지.
- 아공간 36칸, 개인 저장, v3 저장 키/스키마 유지.
- transact/recover/current/isPlain 저장·복구/보관 안전 규칙 자체는 변경 없음.
- 보안관/사신 및 기타 RPG 시스템 변경 없음.

[검증 상태]
- 정적 검사 대상. Bedrock 실기기 미검증.
