Mechanics RPG v1.4.44 - DDUI NO-FLICKER PROOF TEST

목적
- v1.4.43의 검증된 9x3 상자형 아공간 UI는 그대로 유지합니다.
- @minecraft/server-ui 2.1.0 CustomForm이 버튼 클릭 후 화면을 유지하는지 실기기에서 검증하는 별도 테스트 모드를 추가합니다.

실행
- 일반 아공간 사용: 기존 v1.4.43 상자형 UI (동작 변경 없음)
- DDUI 테스트: /scriptevent geumyi:subspace_ddtest

DDUI 테스트 기능
- 같은 v3 아공간 저장 데이터와 transact/recover 로직 사용
- 아공간/인벤토리의 현재 비어 있지 않은 스택만 목록으로 표시
- 버튼 클릭 시 폼을 닫지 않고 넣기/빼기 실행 후 Observable로 즉시 갱신
- 보관 불가 특수 데이터 아이템 차단 유지
- 화면이 열려 있는 동안 사용량 상태 라벨 실시간 갱신

중요
- 이 버전은 '무깜빡임 가능 여부' 실기기 검증용입니다.
- server-ui 2.1.0 CustomForm에는 9칸 가로 grid/multiButtonRow와 아이템 아이콘 API가 없어 기존 상자 외형을 그대로 옮기지 않았습니다.
- v3 저장 형식, 36칸 역사 배열, 활성 27칸, 저널 복구 로직은 변경하지 않았습니다.
