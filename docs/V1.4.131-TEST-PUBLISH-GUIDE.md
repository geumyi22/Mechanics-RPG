# v1.4.131 TEST source publication and release guide

**Status:** upload helper prepared; the TEST release has not been published. Existing Stable v1.4.48 and all previous releases remain unchanged.

## Why this is not yet published

The connected GitHub API can update code and Git objects, but cannot attach the conversation's actual binary .mcworld/.mcaddon data to GitHub Releases. The exact candidate bytes are in the ZIP bundle. Do not treat a documentation-only release or a tag's automatic source ZIP as the actual v1.4.131 world/source.

## Required local input

Mechanics_RPG_v1.4.131_GITHUB_UPLOAD_PREPARED_TEST_BUNDLE.zip contains:
- v1.4.131_VIBRANT_VISUALS_COMPAT_TEST.mcworld: user world with possible LevelDB/player data
- v1.4.131_Integrated_Packs_RC.mcaddon: 7 internal BP/RP packs
- v1.4.131_ALL_PACKS_SOURCE_NO_DB.zip: 7 packs and world linkage JSON; user world DB excluded
- CardMagician_v1.4.131_SOURCE.zip: only the 2 main RPG packs (not the entire seven-pack source)
- Audit JSON, verified SHA256SUMS, Korean pre-release notes

## On a Windows PC

Install Git for Windows and GitHub CLI, then authenticate with gh auth login. Download tools/publish-v1.4.131-test.ps1 from this repository and place it beside the prepared bundle. Run:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\publish-v1.4.131-test.ps1 -BundlePath ".\Mechanics_RPG_v1.4.131_GITHUB_UPLOAD_PREPARED_TEST_BUNDLE.zip"

The helper validates file hashes and the seven source pack manifests first. It asks whether to include the user-world binary: type PUBLIC-WORLD **only after explicitly reviewing whether its LevelDB/player information is appropriate for a public GitHub Release**. Pressing Enter omits the world. Type PUBLISH TEST only if you approve the public Pre-release.

## Actions taken by that script when executed

1. Clone this GitHub repository in a temporary local directory.
2. Create branch candidate/v1.4.131-source-20261022 without touching main or the older release tags.
3. Add exact seven-pack source under candidates/v1.4.131/; no user LevelDB included in the source branch.
4. Push that candidate branch.
5. Publish a GitHub **Pre-release** tagged test/v1.4.131 targeting the candidate source commit.
6. Upload the exact verified addon, full seven-pack source, audit report and checksums; also upload the .mcworld only if the privacy prompt was accepted.

The TEST tag deliberately does not begin with v, so it does not trigger the normal version-locked Stable release.yml workflow. The existing Stable version validation is preserved. If the script fails after pushing the branch, the branch may remain: inspect it and complete the release manually; the helper will not overwrite it upon retry.

## Known issues and non-goals

- The P3.5 armor stand protection failed in an actual in-game test.
- Full Card Magician/P4/Vibrant Visuals/Bedrock gameplay E2E not run.
- One external behavior pack and three external resource packs are referenced but not bundled.
- User world DB and player information require a privacy review before publication.
- Do not mark this build Stable or replace main/source/world v1.4.48 without implementing and verifying the release gate.
