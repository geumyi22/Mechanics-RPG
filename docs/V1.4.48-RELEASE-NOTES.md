# Mechanics RPG v1.4.48 — SAFE GUARD

v1.4.48은 9×3 상자형 아공간 경로로 복귀하고 위험 아이템 저장을 차단한 **정식 Release**입니다.

> 검증 경계: source/static/package 검증은 PASS지만, **v1.4.48 exact-package 전체 Bedrock release-gate E2E는 NOT RUN**입니다. 따라서 이 문서에서는 v1.4.48을 “안정화 검증 완료”로 표현하지 않습니다.

## 주요 변경

- 아공간 9×3 / 27칸
- 기존 v3 데이터 및 journal/stage recovery 유지
- 역사적 28~36번 슬롯 안전 이전 로직 유지
- 무기/스킬템/내구도/인챈트/이름/Lore/동적 속성 아이템 저장 차단
  - `아공간이 그 힘을 버티지 못합니다.`
- 셜커/Bundle 저장 차단
  - `아공간이 셜커를 거부합니다.`
- 보안관 탄환/6발 묶음은 기존 안전 예외 유지
- Sheriff/Reaper/Quest/Shop 등 다른 RPG 시스템은 SAFE GUARD 범위에서 변경하지 않음

## 무기 표시

사신 대낫과 보안관 리볼버의 기존 1인칭 렌더 경로는 v1.4.48 Release source에서 변경하지 않았습니다.

이후 진행된 무기 3인칭 TEST1~28은 로컬 실험으로 종료되었으며 **v1.4.48 Release/source/main에 포함되지 않습니다.**
