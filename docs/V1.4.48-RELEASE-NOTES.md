# Mechanics RPG v1.4.48 — SAFE GUARD

v1.4.48은 아공간 실험 경로를 정리하고, 실기기에서 확인된 9×3 상자형 구현을 안정화 기준으로 복귀한 릴리즈입니다.

## 주요 변경

- 아공간 9×3 / 27칸
- 기존 v3 데이터 및 journal/stage recovery 유지
- 역사적 28~36번 슬롯 안전 이전 로직 유지
- 무기/스킬템/내구도/인챈트/이름/Lore/동적 속성 아이템 저장 차단
  - `아공간이 그 힘을 버티지 못합니다.`
- 셜커/Bundle 저장 차단
  - `아공간이 셜커를 거부합니다.`
- 보안관 탄환/6발 묶음은 기존 안전 예외 유지
- Sheriff/Reaper/Quest/Shop 등 다른 RPG 시스템은 SAFE GUARD 범위에서 변경하지 않음
