# 메크닉스 RPG — 현재 월드/지형 인계 (2026-10-10)

> 최신 기준 문서. 옛 중세 마을 설계안은 과거 기록이며, 현재의 건축 지시가 아닙니다.

## 현재 결론 및 작업 중단 범위
- **후지가 직접 마을을 건축**합니다. AI가 만든 중세 마을 자동 생성 결과물은 최종 채택되지 않았습니다.
- AI가 향후 지원할 영역은 사용자가 다시 요청하는 경우의 **자연 지형**입니다. 현재 지시는 GitHub 파일 정리뿐이며 새로운 월드 파일/코드/릴리스 작업은 중단합니다.
- 채팅에서 생성된 자연 지형 v2.4 + RPG v1.4.100 시험 월드가 후속 작업 입력으로 승인된 적이 있지만, GitHub 공식 소스와는 다릅니다.
- GitHub main 소스/Release: **v1.4.48 SAFE GUARD**, source/world 294개 파일과 SOURCE-MANIFEST 유지. v1.4.48 full Bedrock E2E: **NOT RUN**. 마지막 정식 전체 release-gate E2E PASS: **v1.4.20**.
- 채팅의 v1.4.100 월드 및 Side Nature v1~v4 .mcworld 파일은 GitHub main/source/Release에 업로드하거나 승격하지 않았습니다. 사용할 때 다시 원본 파일과 SHA-256을 확인해야 합니다.

## 사용자 요구 기준 — 향후 자연 지형 작업이 재개될 경우
1. 원본 RPG, 던전, 모험 지형의 데이터 및 게임팩은 그대로 보존하고 복제본에만 제작.
2. 던전과 새 지형은 **약 10블록 분리**하고 서로 연결하지 않기. 비운 구간이 게임에서 재생성되는지도 검증.
3. 사용자가 마을을 직접 짓도록 **약 180×185~200블록 규모의 실용적 평지**를 확보하되 똑같은 높이의 기계적 평탄화는 피하기.
4. 던전 주변 산의 실제 고도/경사/침식 형태를 기준으로 산을 설계하기. 초고산, 한쪽에만 있는 산, 원형 기계식 분지 모두 금지.
5. 자연스러운 산기슭·사면·능선·봉우리, 암석/초지/수목 전이 구현. 거대한 수직 암벽/사각 절단면/빈 월드 틈 방지.
6. 풍경뿐 아니라 청크 경계, 다중 고도, 스폰과 멀티플레이 성능, 실제 월드에서의 보임 확인.
7. 참고 이미지, 높이맵, 자체 렌더링, 게임 실제 스크린샷을 반드시 구분.
8. 새 제작은 **별도의 사용자 지시 후** 진행. 정적 검증만으로 완성 선언 불가.

## 중세 마을 자동 건축에서 발견된 미해결 문제 11건 (역사 기록)
1. 도로 돌/자갈 과다 사용과 규칙적인 반복 무늬
2. 인위적·획일적인 나무 수형과 배치
3. 얇고 금이 간 듯한 성벽/부자연스러운 성문
4. 중앙 광장 시설 품질 부족, 당시 사용자는 중세풍 분수를 요구
5. 판유리 연결 불량과 잘못 설치한 다락문
6. 집 외관·창문·지붕·실내의 전체적인 마감/비례 부족
7. 정면에서 의도치 않은 좌우 비대칭
8. **텍스처가 정상 표시되지 않는 블록**: 흙이라고 단정했던 분석은 사용자가 정정하여 철회. 실제 블록 ID/state/RP 확인 필요
9. 쓸데없이 높은 실내와 누락된 2층/천장
10. 인위적으로 네모반듯한 농장
11. 주택가·상가·철물점/공방·농장 구역 구분 실패

이 기록은 동일한 생성 방식을 되풀이하지 않기 위한 참고일 뿐, 후지가 직접 지을 마을에 AI 건물을 추가하라는 뜻이 아닙니다.
