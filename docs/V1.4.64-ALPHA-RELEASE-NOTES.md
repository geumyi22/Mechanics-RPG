# Mechanics RPG v1.4.64 — Hacker Redesign Alpha

**Pre-release / 미검증 실험판 / 알려지지 않은 버그 가능 / Bedrock E2E 미실행**

## 내용
- feature/2026-10-07-v1.4.64-class-redesign의 해커 리디자인 Alpha 코드 기준입니다.
- 리볼버 위치 변경 및 이전 해커 시험 기능이 포함되어 있으며, 기존 main v1.4.48의 정식 기준을 교체하지 않습니다.
- 원본 브랜치에서 누락됐던 해커 아이템 5종의 이미지에 구분 가능한 임시 픽셀 아이콘을 추가했습니다.
- 기존 SOURCE-MANIFEST 기록의 불일치 및 신규 5종 PNG를 포함한 파일 목록·SHA-256을 다시 기록하고 정적 검증을 수행한 뒤 게시합니다.

## 알려진 제한/주의
- 아이콘 5종은 임시 디자인이며 지후의 최종 승인을 받은 디자인이 아닙니다.
- 해커 스킬 동작, 3인칭 무기 렌더링, 밸런스, 멀티플레이 및 저장/재접속은 실제 게임에서 검증하지 않았습니다.
- Alpha에는 사용자 미지정 값으로 설정된 Impair Defenses의 피해량 25가 들어 있습니다.
- 이번 릴리스는 **버그를 허용한 실험 배포**이며 정상 작동을 보증하지 않습니다. 기존 월드에 직접 덮어쓰지 말고, 반드시 복제본에서 시험하세요.
- 채팅에서 만든 중세 마을/Side Nature 테스트 맵은 이 릴리스에 포함되지 않습니다.
