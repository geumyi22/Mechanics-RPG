# v1.4.131 — 2026-10-22 사용자 실게임 확인 사항

> **사용자 확인 업데이트 / 릴리즈 검증 범위 미확정.** 본 기록은 사용자가 2026-10-22 채팅에서 직접 정정한 내용을 보존한다. 기존의 "모든 카드 술사 기능 미검증" 또는 "갑옷 거치대 보호가 현재에도 실패"라는 단정 대신 아래 구분을 사용한다.

## 사용자에게서 직접 확인된 내용

- **갑옷 거치대 보호:** 사용자는 "갑옷 거치대 보호가 검증됐음"이라고 보고했다. 과거 P3.4/P3.5 테스트에서 실패했던 기록은 해당 시험본의 역사적 결과이며, **현 시점 모든 빌드의 보호가 실패한다는 뜻으로 확대하지 않는다.**
- **카드 술사:** 사용자는 **일부 기능**이 실게임에서 검증됐다고 보고했다. 다만 이번 정정만으로 *어떤 스킬, 어떤 게임 모드, 어떤 빌드, 어떤 검증 절차*가 통과했는지는 특정할 수 없다. 전체 E2E PASS로 확대하지 않는다.
- 그 외 이슈의 해소 여부, **Vibrant Visuals**, 서바이벌/모험/크리에이티브 전체 모드, 멀티플레이, 저장/재접속 회귀 검증은 이 보고에서 특정되지 않았다.

## 검증 증거의 정확한 상태

| 대상 | 상태 | 증거 범위 |
|---|---|---|
| 갑옷 거치대 보호 | **USER-REPORTED PASS** | 사용자 직접 확인, 빌드/조건 미기록 |
| 카드 술사 | **PARTIAL USER-REPORTED PASS** | 일부 기능 확인, 항목 미기록 |
| 최신 v1.4.131 exact-package 전체 회귀 | **NOT DOCUMENTED AS FULL PASS** | 정적 검사 기록과 부분 사용자 보고는 존재 |
| Vibrant Visuals 호환성 | **NOT CONFIRMED** | 설정/정적 검사는 그래픽 실기기 검증 대체 불가 |
| 외부 BP 1개/RP 3개 의존성 | **KNOWN DEPENDENCIES** | 기존 로컬 감사 문서 참조 |

## 소스 및 배포 경계

- 현재 GitHub `main/source/world`의 릴리즈 기준은 **v1.4.48**로 확인되며, 로컬 v1.4.131 파일과 **동일한 게임 소스가 아직 GitHub에 게시되었다는 근거는 없다**.
- 기존 공개 v1.4.20, v1.4.48, v1.4.64, v1.4.118 릴리즈/태그를 훼손하지 않는다.
- 사용자가 요청한 GitHub 최신 Stable 게시를 위해서는 **정확한 v1.4.131 소스/바이너리 대응**, 외부 팩 의존성 및 공개 월드 DB/플레이어 데이터 범위 확인, 정확한 실게임 검증 범위의 릴리즈 노트 명시가 필요하다.
- 이 문서는 성공 판정을 임의로 추정하지 않는 **정정 이력**이다. 과거 실패 기록은 삭제하지 않고 당시 시험본 결과로만 유지한다.
